# Runtime Recovery

Recovery messages are result observations generated by the runtime. They
correct model shape errors without adding a second output protocol.

## Empty Emit

An empty response gets a short runtime prompt asking for Markdown prose, a bash
block, or bare `exit`.

## Invalid Lenos Run

If the tag parser rejects the emit, the runtime shows the offending line, a
caret, help text, and a suggested rewrite.

## Invalid Bash

If the mvdan Bash parser rejects a run block, the runtime sends the syntax
error back and asks the model to fix the bash quoting or structure.

## Tool-Call Wrappers

If the model emits XML, JSON, or bracket-shaped tool-call markup, the runtime
deletes that assistant row and sends a high-salience alert. Replaying the bad
wrapper would teach the next turn to copy it.

## Command Not Found

If bash reports the first missing command, the runtime prepends an alert before
the normal result envelope. This covers both real missing binaries and
chat-shaped lowercase prose that was ambiguous enough to execute.

## Timeout

A timeout is stored as a command result with exit code 124 and a re-prompt
suggesting bash-native `timeout`.
